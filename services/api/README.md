# TraceAML API (`services/api`)

uv-managed FastAPI service. Python >= 3.12.

## Setup

Run these commands from the repository root:

```sh
uv sync --project services/api
uv run --project services/api fastapi dev services/api/src/api/app.py
```

Dev tools are in the `dev` group:

```sh
uv sync --project services/api --group dev
uv run --project services/api --group dev ruff check services/api/src
uv run --project services/api --group dev pytest services/api/tests -q
```

The API depends on the editable local `graph/` project. It reads the ignored
`artifacts/runs/hi-small-v8/baselines/inference_scores.parquet`,
`baseline_config.json`, and `baseline_metrics.json` artifacts generated by the
ML commands in the repository README. It fails closed if score columns include
labels, split assignments, or typology fields.

## Health

`GET /api/health` returns:

```json
{ "status": "ok", "falkordb": "available", "version": "0.1.0" }
```

`falkordb` is one of `available`, `unavailable`, `not_configured`.
Configure with `TRACEAML_FALKORDB_HOST` (unset means `not_configured`).
Responses never include hosts, ports, credentials, or dataset labels.

## Routes

- `GET /api/alerts?limit=50&offset=0` returns a risk-ranked replay queue with
  timestamp and deterministic `allow`/`review` decision.
- `GET /api/benchmarks` returns the saved logistic regression and LightGBM
  metrics.
- `POST /api/investigations` accepts a transaction ID and bounded depth, time
  window, and result limit. It loads the stored risk score, applies the
  validation-selected threshold, then runs all approved FalkorDB tools and
  validates the returned evidence references.

Set `TRACEAML_GRAPH_NAME` to the graph containing the replay transactions. The
current report is deterministic; no LLM provider is configured. The graph
scope and local capacity measurements are documented in `graph/README.md`.
